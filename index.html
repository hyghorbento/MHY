Configuração do Supabase e instruções

1. Crie um projeto Supabase. No topo deste HTML, preencha SUPABASE_URL e SUPABASE_ANON_KEY com os dados públicos do projeto.

2. Execute o SQL abaixo no SQL Editor. Crie seu usuário em Authentication → Users. Entre com a mesma conta no PC e celular. As políticas isolam os dados por usuário.

3. Sirva este arquivo por HTTP local ou publique em hospedagem HTTPS. A sincronização usa Realtime e recarrega os dados ao retornar à aba. Fotos são comprimidas para JPEG de até 640 pixels e salvas em Base64 no banco.

Conexão com o Supabase

Use somente a chave pública. Não informe senha, chave secret ou service_role.
